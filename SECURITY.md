# Security

Found a way to get past a token's permissions, leak a token, or make the agent act on game text as instructions? Report it privately through [GitHub's security advisories](https://github.com/MairwunNx/minecraft-mcp/security/advisories/new), not in a public issue. I answer there, and fix the newest release first.

A bug in WorldAPI itself, the plugin on the server, goes to [its own advisories](https://github.com/MairwunNx/minecraft-worldapi/security/advisories/new).
